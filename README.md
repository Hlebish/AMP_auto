# AMP Auto

Единый подборщик автозапчастей на основе складского каталога.

## Что умеет
- поиск только по товарам с остатком;
- поиск по каталожному номеру;
- поиск по OEM / cross-number;
- поиск по марке, модели, двигателю и названию;
- подбор по автомобилю;
- русский / украинский / английский ввод для основных марок;
- подключение к Firebase Realtime Database проекта Warehouse Map;
- поиск адреса детали на складе;
- интерактивная карта с переходом к найденной ячейке;
- тёмная тема;
- сохранение загруженного каталога в браузере.

## Формат Excel

Ожидаются колонки:
catalog_number, manufacturer_parts, name, description, quantity, price, original_number, marks, models, engine, image

В подбор попадают строки, где quantity содержит положительный остаток. Значение 5+ считается наличием.

## Важно

AMP Auto не изменяет данные Warehouse Map. Карта используется как источник адресов хранения.
Каталог Excel хранится локально в браузере пользователя и может быть обновлён кнопкой «Каталог Excel».
